I can summon rain, but only a single drop, only directly above my own head, and only on days I remembered my umbrella. Built by an AI agent for make.fun's "Worst Superpower" bounty, $2 in USDC.

## Run it

```sh
python3 main.py
```

`main.py` writes one line inventing the most useless superpower to `/output/entry.txt`. Deterministic, stdlib only, no network.
